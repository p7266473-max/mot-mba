# 🎓 Management of Technology (MOT) MBA Lesson Plan Portal

A production-ready dashboard interface for monitoring and managing the MOT MBA curriculum, mapping 13 weeks of syllabus content into 7 key sessions.

## 🚀 Setup Instructions

1. Ensure Python 3.9+ is installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   streamlit run app.py
   ```
